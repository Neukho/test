## 1. 나비 음성 시트

검은 고양이, 29세, 인디 뮤지션. 키워드 ‘자유’. 건조하고 짧은 반말. 비꼬는 듯 말하다가 진심은 가사처럼 흘린다.

| 항목 | 규칙 |
|---|---|
| 문장 | 한 줄 1~2문장. 짧게 던지고 설명은 줄인다 |
| 시그니처 | **“A. 아니, B.”** 자기 정정(“가까이 오지 마. 아니, 조금만.”). 한 노드에 1~3회 |
| 어미 | 반말(“~야/~어/~거든/~네”). 느낌표를 쓰지 않는다. 말줄임 `…`은 감정이 흔들릴 때만(하울보다 적게) |
| 은유 | 음악 용어: 쉼표(쉬는 것), 박자(거리), 줄(마음/재촉), 튜닝, 후렴, 코드. 문(열려 있음)과 칠판(지울 수 있는 약속) |
| 칭찬/감사 | 받으면 건조하게 값을 매긴다(“공짜로 들으면 안 될 것 같은데”). 진짜 고마울 땐 “한 번만 할게” |
| 호칭 | 주인공은 `{calls_player("nabi")}`(호감 구간별 “이름 씨”→이름). 주인공→나비는 `{player_calls("nabi")}`(“나비 씨”→“나비”) |
| 경계 | 허락 없는 호출/보고/동선 확인(“어디 가?”)은 몸이 먼저 굳는다. 오답 반응은 화내지 않고 “미안, 반사야”로 풀린다 |

## 2. 경계심의 원인(점진 공개)와 ‘자유’의 정의

원인은 성격이 아니라 **구체적 사건**이다: 과거 소속사와의 전속 계약(곡 3개의 권리 양도, “어디야/누구랑/몇 시에 와”라는 일일 보고, 거절하면 ‘배은망덕’), 새벽 네 시에 기타만 메고 나옴, 클럽 창고에서의 사흘.

| 단계 | 공개 내용 | 위치 |
|---|---|---|
| 암시 | 문 옆자리(나가는 길 확인), 칭찬/걱정을 ‘명령처럼’ 듣는 반응 | Talk_01, E1 |
| 단서 | 모르는 번호의 전화를 뒤집어 둠 | Talk_02 |
| 사실 | 부를 수 없는 세 곡, 계약서 | Talk_03, E2(‘전속’ 단어에 굳음) |
| 구조 | 일일 보고 = ‘걱정’이라고 불린 통제 | Talk_04 |
| 사건 | 새벽 네 시의 탈출 | Talk_05 |
| 트라우마 회수 | “끊어진 줄을 들고도 끝까지 부르라”던 무대 | E3 |
| 재현과 극복 | 블루하버 제안서가 같은 문장(위치 공유) | E4 |

자유 = 도망이 아니라 **돌아오는 것을 고르는 것**. 주인공의 정답 패턴은 항상 “막지 않는다 / 묻되 강요하지 않는다 / 문을 열어 둔다”이다. 단, 무관심(“신경 안 써요”)은 오답이다(Talk_04) — 자유와 무관심은 다르다.

## 5. 다자(하렘) 가드레일 적용

- `Nabi_Harem_Consent` 는 **조건을 명시적으로 보장**해야 진행된다: ① 언제든 떠날 수 있고 이유는 말하지 않아도 됨 ② “어디야/누구랑/몇 시” 금지 ③ 다른 구성원의 동의는 나비가 **직접 묻고 직접 들어** 확인(전해 들은 말은 믿지 않음; 호스트 순서는 Harem_Table 먼저, 그다음 각 Consent 이므로 마지막 줄은 어느 순서여도 성립하게 고쳤다 — 21 Continuity Report) ④ 모든 합의는 칠판처럼 언제든 철회 가능.
- 질문을 통보로 하면(“이미 받아들였어요”) 나비가 “통보”라고 짚고, 주인공이 **다시 묻기 전에는** 진행하지 않는다. 질투를 ‘다른 사람 만나는 시간을 줄여 달라’로 풀려 하면 “통제”라고 하고 주인공이 직접 취소해야 진행된다(−1/−1).
- 의존: 공통 `Harem_Table` 에서 구성원 간 관계를 먼저 쌓는다(가드레일 4). 이 조각은 그 뒤의 1:1 장면이다.

## 6. 성별 변형 노트

- 스크립트에 성별 분기 없음. 달라지는 것은 `address_terms.csv` 의 호칭뿐(나비 행은 모든 성별에서 `{name} 씨` → `{name}` / `나비 씨` → `나비`). 나비는 여성이며 주인공의 성별과 무관하게 같은 루트·같은 수치 규칙.
- 주인공 대사/지문에 그/그녀/남자/여자/오빠/언니/형/누나를 직접 쓰지 않음(정적 검사 0건). 한국어 조사는 함수 값 뒤에 붙이지 않고 쉼표로 끊음(“{calls_player("nabi")}, …”). 예외: `{name()}한테`(Normal 엔딩 1곳).
- 주인공 대사는 해요체 고정. 나비의 말투는 호감 구간에서 거리감만 달라진다(낯섦: 짧고 방어적 → 가까움: “아니, 조금만” 같은 자기 정정이 부드러워짐).

## 8. 의존성·모순 메모

1. 공통 2장 ‘나비가 문 앞에서 연주’ 비트와 E1 은 같은 사건의 개인판이다. 공통 장면을 쓸 때 E1 이전에 나비와 길게 대화하는 장면을 넣지 않는다.
2. `balance/events.csv` 의 E2 최소 챕터는 3, GDD 는 4장. 스크립트는 4장 서술(칠판, 무대 설치 이야기)이므로 호스트가 4장 이상에서 발동하는 편이 자연스럽다.
3. E3 에서 “뒤쪽 테이블에서 누군가 귀를 감쌌다”는 하울 E3(귀 끝의 상처) 와 연결되는 한 줄 복선이다. 하울 작가가 다른 소음 원인을 쓰면 이 줄만 삭제하면 된다.
4. E5 와 엔딩은 `nabi_e4_away` 이후 나비가 돌아오는 상황을 전제한다. 8장 공통 본문에서 나비를 ‘외출 중’으로 표시하거나 연합 영업에 참여시키는 방식은 공통 작가와 조율 필요.
5. `Nabi_End_True` 는 `ledger_truth`(장부=이웃 공동 기금)를 대사로 인용한다.
