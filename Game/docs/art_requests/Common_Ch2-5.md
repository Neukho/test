# 일러스트 제작 요청서 — 공통 2~5장

규칙: 주인공은 뒷모습·손·그림자로만 표현. 전연령. 파일명 `CG_<KEY>.png`.

## 배경 (새 ID 없음, 매니페스트 기존 사용)
- `cafe`(morning/day/dusk/night), `harbor`(dusk, Ch5_Outro). 2층(위층 바)이 열린 내부 컷은 `cafe` 밤 변형 하나로 충분.

## CG

### COMMON_CE03 — 임대료 회의 (`CG_COMMON_CE03.png`)
- 사용: `CE03_RentMeeting` 마지막(`show_cg` ~ `hide_cg`). 영업 전 오후 가게 홀.
- 구도: 테이블을 위에서 약간 내려다본 컷. 서명된 계약서, 영수증 둘, 찻잔 세 개, 가운데에 ‘18%’가 굵은 선으로 그어진 종이(`같이 정한다` 글씨가 종이 밖으로 삐져나옴).
- 인물: 범준의 큰 손(펜), 하울의 손(찻잔), 주인공의 손. 얼굴 없음.
- 조명: 창가 오후 햇살, 종이 가장자리에 빛.
- 대사 위치: 하단. 표정 키는 불필요.

### COMMON_SHOW — 공연 전 만석의 홀 (`CG_COMMON_SHOW.png`)
- 사용: `Ch5_Show`(공연 십 분 전까지, 직후 개인 이벤트가 이어짐).
- 구도: 입구 쪽에서 안쪽 무대를 바라보는 와이드 컷. 안쪽 모퉁이의 낮은 단과 노란 전구, 창가의 작은 화분들, 만석의 이웃들 뒷모습.
- 맨 뒤 구석 테이블에 하울의 실루엣과 배전함(전기 상자) 보이게.
- 조명: 낮고 따뜻한 노란색 대 짙은 밤 창.
- 소품: 범준의 화환과 굵은 글씨 쪽지(선택).
- 금지: 기타 줄이 끊어지는 순간(`NABI_E3` 소유)을 그리지 않는다.
