# 일러스트 제작 요청서 — 요한 (CG 6장 + 스탠딩 사용 현황)

> 일러스트는 사용자가 직접 제작합니다. 이 문서는 프롬프트가 아니라 **제작 요청서**입니다.
> 파일명만 맞추면 코드 수정 없이 반영됩니다(`ArtLoader` 폴백). 주인공은 **얼굴을 그리지 않고** 손·그림자·1인칭 시점·뒷모습으로만 표현합니다(성별·종·외형 선택 무관, GDD §0-5).
> 캐릭터 고정 요소(`02_Art_Plan.md` §2): 은여우, 슬림·중간 키, 은백색 털 + 꼬리 끝 흰색, 푸른 눈, **세련된 안경**. 노출 없는 의상, 성인 비율. 여우 종 클리셰(교활한 눈매·음흉한 미소)는 피하고, 눈매는 부드럽게.
> 요한의 연기 키워드: **안경**(올리면 진담 / 벗으면 가장 솔직), **만년필·수첩**, **은빛 귀와 꼬리 끝의 감정 표현**.

## 공통 제작 규칙

| 항목 | 규격 |
|---|---|
| 파일명 | `CG_Johan_E<N>.png` (N=1~6) |
| CG ID | `JOHAN_E1`~`JOHAN_E6` (시나리오의 `<<show_cg ID>>` 와 동일) |
| 해상도 | 1920×1080(16:9), PNG. 대사창이 하단 약 25%를 가리므로 **중요 요소는 상단 75% 안에** |
| 등장 | 요한 + 주인공의 손/그림자/시점. 다른 인물은 등장시키지 않음 |
| 표정 키 | `neutral / smile / shy / angry / sad / surprised`(스탠딩과 동일 키워드). CG 는 장면별 단일 표정 |
| 사용 방식 | CG 가 떠 있는 동안 스탠딩은 숨겨집니다(스크립트의 `show_standing` 은 CG 중에도 호출되지만 화면에는 CG 만 보이게). 필요하면 CG 에 표정 변형을 요청해 주세요 |

## 스탠딩 사용 현황 (시나리오 기준)

시나리오는 **의상 인자 없이** `show_standing johan <표정>` 만 사용합니다(Howl 루트와 동일 관례). 의상 선택은 호스트/연출 쪽에서 장면별로 지정해 주세요. 권장 의상은 아래와 같습니다.

| 의상(`02_Art_Plan.md`) | 권장 장면 |
|---|---|
| 평상복(린넨 셔츠 + 카디건) | 대화 Talk 01~06, 선물 반응, 일반 데이트, E1~E3 |
| 가게 유니폼 대신 **평상복 유지** | 요한은 직원이 아니라 손님이므로 유니폼은 쓰지 않음 |
| 데이트복(오프화이트 재킷 + 스카프) | `Johan_Date_BookStreet`, `Johan_Date_NightMarket`, E5, 엔딩 3종 |

| 표정 | 사용 횟수(스크립트 전체) | 주요 장면 |
|---|---:|---|
| smile | 56 | 장난·농담, 인정받았을 때, 마무리 |
| neutral | 41 | 기본, 진지한 설명 |
| shy | 24 | 칭찬을 받을 때, 진심에 가까워질 때(요한은 `shy` 가 ‘진담’ 신호) |
| surprised | 23 | 예상 밖의 정직한 질문·배려를 받을 때 |
| sad | 6 | 오답 반응, E2·E3·E4 의 상처/취약함 |
| angry | 0 | **사용하지 않음**(요한은 화를 내지 않고 말이 짧아지거나 농담으로 접는다) |

### 스탠딩 제작 참고
- 안경은 얼굴 레이어가 아니라 **바디/헤드 공통 요소**로 두어 표정 6종에서 동일하게 보이게 해 주세요(진담 연출은 대사로 하고, 안경을 벗는 연출은 CG(E3, E5, E6)로만 합니다).
- `shy` 는 귀 끝이 붉고 시선이 비스듬한 표정, `smile` 은 입꼬리 한쪽이 먼저 올라가는 능청스러운 웃음이되 ‘음흉함’은 피해 주세요.
- 꼬리는 스탠딩에서 보이는 경우 감정(`smile`: 끝이 살짝 흔들림, `sad`: 처짐)과 일치시키면 좋지만 필수는 아닙니다.

## 배경 요청(참고, 요한 루트에서 사용하는 `bg` ID)
`cafe day/night/dawn`, `book_street day`, `night_market night`, `harbor night/dusk`(스팟 id 는 `balance/spots.csv`). `harbor` 는 하울 루트와 공유.
