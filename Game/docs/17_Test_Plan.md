## 4. 수동 QA 매트릭스

변수: 플랫폼(Windows, Android) × 난이도(스토리/노멀/하드) × 주인공 성별(남·여·논바이너리·중립; 호칭/대명사 분기 `PronounResolver`) × 루트 × 엔딩.
전수 곱 = 2 × 3 × 4 × 21 = **504 조합**(엔딩 21 = 개별 6명 × 3 + 공동 2인 + 공동 3인 + 커뮤니티). 13시간 플레이를 504번 하는 것은 불가능하므로 **등급별로 줄입니다**.

### 4.1 엔딩 21종 (모든 릴리스 후보에서 각 1회 이상, Windows·노멀 기준)

| # | 루트 | 엔딩 | 도달 방법 메모 |
|---|---|---|---|
| 1–3 | 하울 | 노멀 / 굿 / 트루 | 트루: `howl_key` + 장부 진실(`ledger_truth`) |
| 4–6 | 요한 | 노멀 / 굿 / 트루 | |
| 7–9 | 범준 | 노멀 / 굿 / 트루 | |
| 10–12 | 하루 | 노멀 / 굿 / 트루 | |
| 13–15 | 곰석 | 노멀 / 굿 / 트루 | |
| 16–18 | 나비 | 노멀 / 굿 / 트루 | |
| 19 | 공동 2인 | 기준(호감 75 / 신뢰 34 / 이벤트 4, 전원 동의) | 밤 행동 집중도 ≥ 80% 권장(시뮬 88%) |
| 20 | 공동 3인 | 기준(호감 70 / 신뢰 30 / 이벤트 4, 전원 동의) | 집중도 ≥ 90% 필요(시뮬 72%, 100%에서 87%) — 고난도 |
| 21 | 커뮤니티 | 미확정 완주 / 동의 누락 / 기준 미달 | |

**효율화(권장):** 게임이 직접 만든 7장 아침 자동 저장을 "픽스처 세이브"로 보관합니다(루트별로 확정 직전 1개 + 동의 직후 1개). 세이브는 HMAC 서명이 있으므로 **손으로 편집하지 말고** 게임으로 만든 파일만 씁니다(`docs/01` §6.3). 7~8장만 재생하면 엔딩 1개당 약 1.5~3시간으로 줄어듭니다.

### 4.2 조합 샘플링 규칙

| 등급 | 언제 | 구성 | 대략 횟수 |
|---|---|---|---|

| **D (난이도)** | 밸런스 변경 시 | §6 시뮬레이션 + 하드 8장 매출/레벨 수동 확인 1회 | 1~2 |

### 4.3 성별 배정표 (등급 A, 엔딩 21종에 성별을 분배)

엔딩 번호 mod 4 로 순환: 0=남, 1=여, 2=논바이너리, 3=중립 (예: #1 여, #2 논바이너리, #3 중립, #4 남 …). 모든 성별이 단독/공동/커뮤니티에 한 번 이상 나오는지 확인하세요.

## 12. 이 계획이 아직 보증하지 못하는 것 (공개 위험)

1. Unity 에서 한 번도 실행하지 않았다: 렌더링, 입력, 씬 전환, Editor 메뉴(빌드/프리플라이트 포함)는 모두 **첫 실행에서 오류가 날 수 있다** — 특히 `BuildTools.cs`/`BuildPreflight.cs` 는 UnityEditor 어셈블리 없이는 컴파일하지 못했고, 문법 탐침만 통과했다.
2. 컴파일 검사는 Unity 6 이 아니라 2021.3 참조 어셈블리 + 일부 shim 으로 수행했다. Input System 은 고정 버전이 아니라 upstream 기본 브랜치를 쓴다.
3. 밸런스 수치는 시뮬레이션 가정(선택지 정답 확률 등)이며 실제 플레이테스트 데이터가 없다.
4. 가드레일·톤·성별 중립의 자동 검사는 휴리스틱 수준이며 사람이 읽어야 한다.
5. 접근성 항목 대부분이 화면 기준 미검증이다.
